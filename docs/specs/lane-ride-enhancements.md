# Lane Ride: five optional improvements

Date: 2026-11-13. These ideas are separate from the v1 baseline specification. They are not assumed implementation scope.

1. **Race your best ride.** Show a faint ghost of a previous attempt and a live score difference, so every familiar course becomes a personal race. Match course version, difficulty and target settings; make the ghost optional.
2. **Unlock visual worlds.** Ride through original neon cities, canyons, orbital stations or underwater tracks. Unlock cosmetic environments and rider trails through course completion, without changing difficulty or selling upgrades.
3. **A fresh daily course.** Generate a new, reproducible course from validated workout blocks. A saved seed allows replay and fair comparison; use a local date and bundled generator so it works offline.
4. **Choose your route.** Occasionally offer a comfortable lane path and a more demanding path with a higher point opportunity. Show the choice early. Keep the selected difficulty's resistance limits fixed, and calculate reachable score ceilings correctly for mutually exclusive routes.
5. **Practice the sections you missed.** The result screen identifies a few missed transitions or cadence holds and offers a short practice ride using those patterns. Practice results stay separate from full-course personal bests.

Suggested order after v1: ghost -> visual worlds -> daily courses -> targeted practice -> branching routes. Branching comes last because it changes content validation and scoring ceilings.
